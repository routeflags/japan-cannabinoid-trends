## 2. 重要な教訓

### 2.1 chargedEventCounts を信用してはいけない

| フィールド | 意味 | 信頼性 |
|-----------|------|--------|
| `chargedEventCounts` | 課金カウンタ | **不正確** |
| `defaultDatasetId` | データセットID | ✅ 正常 |
| `get-dataset-items` | 実際のデータ | ✅ 信頼できる |

### 2.2 日付指定の方法

Actor に専用の日付パラメータはない。`query` 内に X の検索演算子として `since:` / `until:` を書く:

```
"CBX リキッド since:2026-08-01 until:2026-08-08"
```

### 2.3 Apify API の不安定性

| 現象 | 確認済み |
|------|---------|
| 同じ設定で0件と100件が返る | ✅ |
| maxPages を増やしても0件になる | ✅ |
| 複数回試行で異なる結果になる | ✅ |

**対処:** 必ず複数回試行し、最大件数を記録する。
