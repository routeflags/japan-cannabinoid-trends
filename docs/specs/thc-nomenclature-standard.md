## 1. 命名法体系

THC には主に2種類の原子番号体系があります。

| 体系 | 名称 | 状態 |
|------|------|:----:|
| 旧式 | モノテルペン式（Monoterpenoid） | 歴史的文献のみ |
| **現行** | **ジベンゾピラン式（Dibenzopyran）** | **本リポジトリ標準** |

## 3. データセット管理方針

### 3.1 推奨される構造

```json
{
  "canonical_name": "Δ9-THC",
  "aliases": ["Δ1-THC"],

```

### 3.2 集計時の注意

| 投稿 | 検出名 | 実際の分類 |
|------|--------|-----------|
| 投稿A | Δ1-THC | Δ9-THC |
| 投稿B | Δ9-THC | Δ9-THC |
| 投稿C | Δ6-THC | Δ8-THC |
| 投稿D | Δ8-THC | Δ8-THC |

**正しく集計する場合:** 4件の投稿が2種類の位置異性体に言及している

**誤った集計:** 4種類の化合物として数える

---

## 4. 重要な注意

### 4.1 別化合物ではない

旧式名称と現行名称は、**同じ化学構造に異なる番号体系を適用したもの**です。

```
❌ Δ1-THC から Δ9-THC が合成された
✅ Δ1-THC と Δ9-THC は同じ化合物の別名
```

### 4.2 立体異性体は別

本表は**位置異性体のみ**を扱います。立体異性体の区別は別途管理が必要です。

厳密な物質同定には以下も必要：

- 立体配置（R/S 配置）
- InChIKey
- 構造式

### 4.3 Δ6a(7) の読み方

- `6a` は縮合環の原子番号
- 二重結合は炭素6aと炭素7の間
- 「6番目の異性体」ではない
