# Issue: X 元投稿データのリポジトリ内保存禁止が未整理

**ID:** ISS-20261015-PRV-036
**優先度:** P2 (Medium)
**ステータス:** RESOLVED (2026-10-15)
**対象:** `ISS-20261015-COL-030` §4.2 / §10、`datasets/*/data/private/`、X 元投稿データの保存境界

## 概要

以前の記録は「非公開 X データを `datasets/*/data/private/` に保持し、保持期間・更新頻度・削除を管理する」前提で書かれていた。しかし owner 指示により、X の投稿単位データは **リポジトリ配下に保存しない** と決定した。

これは tracked / untracked / gitignored / `data/private/` の別を問わない。したがって、この issue は保持期間や更新頻度を決める問題ではなく、**保存禁止の境界を明文化し、古い保持前提を取り除く問題**として解決する。

## DDD 用語整理

| 用語 | 意味 | リポジトリでの扱い |
|---|---|---|
| X 元投稿データ | 投稿 ID、投稿者 ID、本文、URL、投稿単位 engagement、API レスポンス本文、元投稿に対応付く投稿単位レコード | 保存禁止。`data/private/` も不可 |
| 取得リクエスト証跡 | endpoint、query、期間、ページ番号、HTTP status、取得件数、token digest など本文を含まない実行証跡 | `ISS-20261015-PRV-033` の request-only evidence として扱う |
| 派生集計 | 投稿単位を復元できない粗い集計値 | publication review / gate を通過した場合のみ公開候補にできる |
| 分析・変換コード | 取得・集計・検査の再実行可能な手順 | 追跡対象 |

## 決定（2026-10-15）

- X 元投稿データはリポジトリに保存しない。
- `datasets/*/data/private/` は X 元投稿データの保管場所ではない。
- 保持期間・更新頻度・削除条件は、リポジトリ内保存を前提に決めない。禁止なので「保持」しない。
- 既存の `data/private/` 退避という記述は、過去の暫定処理としてのみ残し、現行方針として使わない。
- 公開可能なのは、機密除去済み request-only evidence、方法論、コード、コードブック、publication gate を通過した派生集計に限る。

## 実施内容

- `ISS-20261015-COL-030` の §4.2 / 未確定事項 / 実装タスク表を、保持管理からリポジトリ保存禁止へ更新した。
- `ISS-20261015-COL-031` の完了条件から「非公開保存領域への採用」を外し、X 元投稿データをリポジトリ artifact にしない方針へ変更した。
- `datasets/cbx-social-trends/methodology.md` と `docs/specs/validation-framework.md` の古い `data/private/` 前提を、履歴記録または保存禁止の説明へ更新した。
- PUB-029 の記録では、承認対象が粗い派生集計のみで、X 元投稿データや中間投稿単位データではないことを明記した。
