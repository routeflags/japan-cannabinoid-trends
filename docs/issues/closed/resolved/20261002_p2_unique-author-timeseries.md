# Issue: ユニーク著者の時系列データがない

**ID:** ISS-20261002-007
**優先度:** P2 (Medium)
**ステータス:** RESOLVED (2026-10-02)

## 概要

X データのユニーク著者数（55アカウント）が静的合計としてのみ報告され、週次推移が公開されていない。

## 影響

投稿数の増加が、少数の販売アカウントの活動増加か、広範な関心の高まりかを区別できない。

## 現状の問題

- 26週レポート自体が「販売系アカウントが中心」と明記
- しかしガイドページの X セクションの所見にはこの限定が反映されていない

## 修正手順

1. 週次ユニーク著者数を算出・公開
2. ガイドページの X セクションに「投稿の多くは販売系アカウントによるものである」という注記を追加
