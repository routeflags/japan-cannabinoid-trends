# Issue: CBD 調査ページの X / YouTube 数値が raw・run metadata と不一致

**ID:** ISS-20261012-CBD-006  
**優先度:** P1 (High)  
**ステータス:** RESOLVED (2026-10-15)  
**対象:** `publication/research_cbd.html`

## 概要

CBD ページの収集期間・件数・取得日が、確認できた raw ファイルや run metadata と
複数箇所で一致しない。公開内容の数値を一次データから照合し、観測・派生・解釈を
分けて修正する必要がある。

## 確認された不整合

### X

- ページ内に「2026-10-01（1日間）」と「2026-07-01〜2026-10-01」の両方の期間がある。
- raw `cbd.json` の100件は `created_at` が 2026-10-01 の範囲に集中しており、
  3ヶ月分の時系列とは確認できない。
- X の分類結果は raw 100件中 99件を有効分類とするが、元データの観測期間と掲載期間が不一致。

### YouTube

- ページは「CBD オイル」unique 28件 / raw 60件と記載。
- 確認した `20261002T064905Z-youtube-cbd-オイル` run は `records.json` 23件。
- ページの取得日 2026-10-05 と、run ディレクトリの収集日 2026-10-02 が不一致。
- 28件が別の run または変換工程の結果か、現状の provenance からは確定できない。

## 影響

公開値が誤解を招くほか、どの収集 run・変換から導出された値か第三者が追跡できない。

## 対応方針

- raw を書き換えず、件数差は upstream / processing / deduplication の各層で調べる。
- 根拠のない値を「正しい方」として選ばず、再現できない数値は訂正または撤回する。
- 既存の 2026-10-06 HTML validation issue は HTML 構文検証 issue であり、本 issue は
  内容・データ整合性を対象とする。

## 完了条件

- [x] X の期間・件数が run ID と raw timestamp に照合される。
- [x] YouTube の 28 / 23 / 60 の定義と由来が説明できる。
- [x] 取得日・期間・件数を raw / metadata / reproducible transformation に一致させる。
- [x] 再現できない記載は削除または未確認と表示する。

## 解決記録（2026-10-15）

全数値をローカル raw と照合し、根拠のない値を訂正した。実測は
`docs/reports/20261015d-cbd-page-provenance-reconciliation.md` §1・§3 に記録した。

### X

- raw の投稿日時は 100 件すべて 2026-10-01（08:52〜20:14 UTC）。ページ記載の検索窓
  2026-07-01〜2026-10-01 を裏付ける run metadata は存在しない。
- ページの「2026-07-01 ~ 2026-10-01」を観測値に訂正し、単日スナップショットとして扱う。

### YouTube（28 / 23 / 60 の由来）

- `60` = `20261005T140054Z-youtube-japanese-apify` の `cbd-oil_raw.json`（2026-10-05 収集）の
  レスポンス件数。`28` = そのユニーク動画 ID 数。ページの取得日 2026-10-05 はこの run と一致する。
- `23` = `20261002T064905Z-youtube-cbd-オイル` の `records.json`（2026-10-02 収集）。
  同一クエリの別取得であり、ページの出所ではない。
- 報告された「取得日と run ディレクトリ収集日の不一致」は、run の取り違えによるものと確定した。

### 数値訂正

- YouTube「CBD オイル」節: 再生数中央値を 14,298 → **14,228**（母集団をユニーク 28 件に統一。
  14,298 は元データ 60 件を母集団とした値だった）。平均・最大・最小・動画長・チャンネル・上位
  動画はユニーク 28 件から再現でき、変更なし。
- YouTube「CBD リキッド」節: 再生数中央値を 22,303 → **21,826**（24 件の中央 2 値の平均。
  22,303 は 13 番目の観測値であり中央値ではなかった）。
- ページの最終更新を 2026-10-15 に更新し、変更理由と照合レポートを記載。run_id は PC-2 のため
  ページに直接書かずレポートに置く（同レポート §4.1）。
