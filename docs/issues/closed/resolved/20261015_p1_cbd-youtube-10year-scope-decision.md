## 概要

`ISS-20261012-CBD-003` は、CBD YouTube 10年収集 run の 2025 年欠落・2023–2024 年部分取得・
provenance 不備を扱っている。一方で、オーナーは「CSV インポートと同時に対応」と指示しており、
その CSV は `ISS-20261015-COL-033` で採用された Apify `youtube-scraper` export 6 件として確認された。

ただし、採用済み CSV は CBD-003 の対象 run を直接補完・置換する根拠にはならない可能性が高い。
問題は、何を「対応」とみなすかが未定義な点である。

## オーナー決定（2026-10-15）

選択肢 2 を採用する:

> 採用済み Apify CBD CSV を 10年系列とは別の YouTube series / snapshot として扱う。

この決定により、採用済み Apify CBD CSV は CBD 報告へ反映してよいが、
旧 10年系列の 2025 年欠測を直接補完・置換する根拠にはしない。
旧 10年系列は不完全系列として扱い、欠測・部分取得・provenance 不備を
別途明示する。

## 訂正: 禁止済み旧手段の説明は根拠にしない

本 issue で一時的に出た「禁止済み旧手段名を使った説明」は、
エージェント側が旧 run 内の error payload を過剰に解釈して説明へ持ち込んだものである。
現行方針では、その旧手段名・使用ログ・error payload を収集方法の正当化や補完根拠として扱わない。

この issue で扱う根拠は、次の観測に限定する。

- `records_2025.json` は観測レコードではなく error payload であり、2025 年の観測値を提供しない。
- `collection_log.txt` は 2025 年を 0 件として記録しているが、これは `observed_zero` ではなく取得失敗 / 欠測として扱う。
- 採用済み Apify CSV は別系列の観測であり、旧 10年系列の 2025 年欠落を直接補完しない。

禁止済み旧手段の再実行・復元・正当化は本 issue の範囲外であり、実施しない。

CSV 自体は動画単位の Apify export で、各行に `input`, `id`, `date`, `channelId`,
`channelName`, `channelUrl` 等を含む。`input` は全行で同一キーワードを示すが、
CSV だけでは CBD-003 の旧 10年 run と同一系列であることは示せない。
CBD 関連の採用済み 2 CSV は `CBD リキッド` であり、年分布は次の通り:

- `14-44-21`（456 rows）: 2014=1, 2015=3, 2016=12, 2017=13, 2018=24,
  2019=55, 2020=27, 2021=152, 2022=59, 2023=31, 2024=19, 2025=33, 2026=27。
- `19-19-00`（393 rows）: 2025=118, 2026=275。

したがって、CSV 実体は「2025 年の `CBD リキッド` Apify 観測を含む」ことは示すが、
CBD-003 対象の「CBD 旧 10年系列」の 2025 欠落を直接補完する証拠ではない。

## 曖昧な点

次の 3 つが混ざっており、どれを実施するかが未決定である。

1. **記載訂正:** 10年系列は補完せず、2025 欠落・2023–2024 部分取得・provenance 不備を README / methodology / publication / matrix に明記する。
2. **別系列として反映:** 採用済み Apify CBD CSV を、10年系列とは別の YouTube snapshot / year run として CBD 報告に反映する。
3. **再取得:** 10年系列を補う目的で、Apify 等により別 run を新規取得する（費用・規約・provenance・採用宣言が必要）。

これらを区別しないまま実装すると、異なる観測系列を同じ 10年系列として扱う誤り、または欠落をゼロ観測として扱う誤りにつながる。

## 影響

- CBD-003 の完了条件が不明確なままになり、Implementer が補完・置換・記載訂正を推測で選ぶリスクがある。
- 採用済み CSV を直接 2025 欠落の補完として使うと、study / collection method / query design の差異を隠す可能性がある。
- publication / matrix に「10年系列完了」と誤解される表現が残る可能性がある。

## 対応方針

- raw data は編集しない。
- 採用済み CSV は、CBD-003 対象 run の直接補完として扱わない。
- まず、CBD YouTube 報告のスコープを明文化する:
  - 10年系列は不完全系列として扱うのか。
  - Apify CSV は別系列として追加するのか。
  - 10年系列を再取得するのか。
- スコープ決定後に、CBD-003 の完了条件・依存・対象文書を更新する。
