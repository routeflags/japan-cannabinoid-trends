# Issue: 欠損データの完全率が公開されていない

**ID:** ISS-20261002-009
**優先度:** P2 (Medium)
**ステータス:** OPEN

## 概要

エンゲージメントフィールド（views, likes 等）の欠損率が公開されていない。欠損値が中央値計算に暗黙的に含まれている可能性がある。

## 修正手順

1. フィールド別の欠損率を算出
2. データ辞書に完全率を公開
3. 欠損値の扱い方針を明記
