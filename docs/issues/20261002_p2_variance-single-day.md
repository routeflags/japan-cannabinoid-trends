# Issue: バリアンス評価が1日分のみ

**ID:** ISS-20261002-010
**優先度:** P2 (Medium)
**ステータス:** OPEN

## 概要

Google Trends の非決定性評価（±3ポイント）が2026-10-01の単一日の再収集のみに基づいている。

## 影響

日次・週次の変動を特徴づけるには不十分。

## 修正手順

1. 複数日（例: 3日以上、1週間）で同一クエリを再収集
2. 日間変動を定量化
3. メソドロジーに評価結果を反映
