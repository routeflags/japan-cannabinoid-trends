# Issue: バリアンス評価が1日分のみ

**ID:** ISS-20261002-010
**優先度:** P2 (Medium)
**ステータス:** DOCUMENTED (2026-10-02)
**対応:** 制約を文書化し、将来の収集計画を記載

---

## 概要

Google Trends の非決定性評価（±3ポイント）が2026-10-01の単一日の再収集のみに基づいている。

## 影響

日次・週次の変動を特徴づけるには不十分。

## 対応内容

1. メソドロジーに制約を明記（単一日評価である旨）
2. 将来のバリアンス評価計画を文書化
3. 実施条件（複数日収集）を定義

## 将来の計画

| 項目 | 内容 |
|------|------|
| 方法 | 同一クエリを3日以上、別々の日に再収集 |
| 対象 | CBX, H4CBH, HHBD, CBX リキッド |
| 評価指標 | 日間変動幅、週間変動幅、標準偏差 |
| コスト | 無料 |
| 優先度 | P2 |
