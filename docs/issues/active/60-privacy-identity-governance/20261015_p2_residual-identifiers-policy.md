# Issue: ハンドル以外の残余識別情報の扱いが未定

**ID:** ISS-20261015-XID-022  
**優先度:** P2 (Medium)  
**ステータス:** OPEN  
**対象:** `publication/guide_cbx_rewrite.html`, `docs/specs/sns-redistribution-assessment.md`, `src/validation/x_identity.py`

## 概要

X の handle・投稿本文・投稿 URL の封じ込めは施行済みだが、**ハンドル以外の残余識別情報**
（店舗・地区名、投稿から特定可能な記述）の扱いは方針未定。

## 確認された観測

- 2026-10-13 に `publication/guide_cbx_rewrite.html` の種別列から店舗地区（「麻布十番」）を
  除去した（個別対応）。
- 機械検査の対象は handle / 本文 / 表示名 / 投稿 URL で、残余識別情報は対象外。

## 影響

- 方針が無いため、今後の公開物で同種の記載が再発し得る。
- 「どこまでが識別情報か」の判断が、その都度の感覚に依存する。

## 対応方針

- 判定基準を定める（何を識別情報とみなすか。事業者情報として公開適切なものとの区別を含む）。
- 基準は機械検査に落とせる形にするか、人手レビューのチェックリストにするかを決める。

- [ ] 基準に応じた検査（機械 or チェックリスト）の実装
- [ ] 既存公開物の遡及確認の必要性判断
