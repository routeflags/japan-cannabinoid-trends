# Issue: 研究ページ内の商業 CTA と COI 開示の矛盾

**ID:** ISS-20261002-003
**優先度:** P0 (Critical)
**検出日:** 2026-10-02
**検出方法:** 独立検証 (Cannabinoid Trend Whitepaper Validator)
**ステータス:** PENDING (管理画面で対応予定)

---

## 概要

研究ガイドページ (`guide_cbx_rewrite.html`) に商業的な商品導線が埋め込まれており、ページ自身の利益相反開示と矛盾している。

## 影響

**ページの自己申告「商品販売が目的ではなく、科学的参照資源として作成されたものです」と矛盾している。ジャーナリストや研究者がこれを商業的フレーミングの証拠として引用する可能性がある。**

## 検出された矛盾

### COI 開示 (L216)

> 商品販売が目的ではなく、科学的参照資源として作成されたものです。

### 商業 CTA (L1375-1408)

> 商品への導線 — CBX 配合商品をご希望の場合は、CBX 商品一覧（成分含有量・価格比較）をご覧ください

加えて、成分グリッドに商業的記述:
- 「定番・初心者向け」
- 「体感重視」
- 「高濃度設計」
- 「上級者向け」

## 経営判断事項（ユーザー管理）

この CTA は **管理画面で後から設定可能** とする方針。

### 説明

1. **研究ページと Commerce ページの役割分担**
   - 研究ページ: 科学的参照資源、データ公開
   - Commerce ページ: 商品選択、購入導線

2. **CTA の置き場所に関する選択肢**
   - **Option A:** 研究ページから完全に除去し、Commerce ページのみに配置
   - **Option B:** 研究ページ下部に「この製品に関心がある方へ」セクションとして分離
   - **Option C:** 管理画面で CTA の有効/無効を切り替え可能にする

3. **推薦事項**
   - Option A または B を推奨
   - 理由: 研究ページの引用可能性を最大化するため
   - CTA があることで、第三者による引用やメディア掲載が阻害される可能性

4. **COI 開示の強化**
   - CTA を残す場合、開示文言に「本ページには商品への導線が含まれます」を明記
   - 研究データと商品推奨を明確に分離

## 対応方針

- [ ] 管理画面での CTA 設定機能を確認
- [ ] 研究ページの CTA 表示方針を決定
- [ ] COI 開示文言を CTA 方針に合わせて更新
- [ ] 修正後、独立検証で再確認
