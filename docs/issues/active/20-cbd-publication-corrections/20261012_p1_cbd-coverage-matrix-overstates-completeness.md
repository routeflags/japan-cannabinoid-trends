# Issue: CBD の総合カバレッジ評価が実データの完全性を過大評価

**ID:** ISS-20261012-CBD-001  
**優先度:** P1 (High)  
**ステータス:** OPEN  
**対象:** `research/strategy/20261008-compound-research-matrix.md`

## 概要

CBD は既存マトリックスで「9/9 = 100%、A、全ソース完備」と評価されている。
しかし、CBD 固有データを run 単位で再確認したところ、プラットフォームの有無と
研究に利用できる期間系列・来歴・再現可能性が混同されている。

少なくとも以下の制約が確認されている。

- X: 複数の期間指定 run が実際には 2026-10 の短期間に集中し、`cbd-1year` は 0 件。
- YouTube: 10 年収集は 2016–2024 のデータがある一方、2025 年データがなく、
  収集 metadata と統合レコードが欠落。
- COA: 公開ページが参照する CBD COA は raw ディレクトリに見当たらない。
- Google Trends: 5 年系列は summary JSON のみで、raw タイムラインを再検証できない。

## 根拠（2026-10-12 読み取り監査）

詳細は CBD 精密監査結果を参照。主な確認値:

| 領域 | 確認された状態 |
|------|----------------|
| Google Trends | 12ヶ月 raw は 53 点。5年は summary の `data_points: 261` のみ |
| X | 1年指定 run は 0 件。実データの日時は主に 2026-10-01 と 2026-10-07/08 |
| YouTube | 10年 run は 3,831 件と報告されるが、2025 年の取得ファイルなし |
| COA | `datasets/cbx-product-coa/data/raw/coa/` に CBD 名のファイルなし |
| 調査ページ | YouTube 件数・X 期間などの記載に raw との不整合あり |

## 影響

「データが存在する」ことを「対象期間を網羅し、再現可能な調査が完了した」ことと
同一視してしまい、成分間・プラットフォーム間の調査状況を誤って報告するおそれがある。

## 対応方針

成分 × データソースの表で、少なくとも次の状態を区別する。

- スナップショットあり
- 期間系列あり（期間、欠測窓、取得上限を併記）
- 取得失敗 / 0 件
- metadata または raw 欠落
- 内容確認済み / 未検証

この issue は評価表の訂正を対象とし、元の raw 観測値は変更しない。

## 完了条件

- [ ] CBD の総合評価を「全ソース完備」から実データに即した評価に改訂する。
- [ ] YouTube の「14 成分すべて 10 年取得済み」という表現を撤回し、snapshot と期間系列を分離する。
- [ ] カバレッジ凡例に件数の有無だけでなく、期間・provenance・欠測を反映する。
- [ ] 表の各記載を該当 dataset の raw / metadata / report と照合する。
