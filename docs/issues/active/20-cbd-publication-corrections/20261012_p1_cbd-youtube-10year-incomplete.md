# Issue: CBD YouTube 10年収集の2025年欠落と provenance 不備

**ID:** ISS-20261012-CBD-003  
**優先度:** P1 (High)  
**ステータス:** OPEN  
**対象:** `datasets/cannabinoid-multi-trends/data/raw/youtube/20261004T142147Z-youtube-cbd-10years/`

## 概要

CBD の YouTube 10年収集 run には年別ページが 83 ファイルあり、報告上の総件数は
3,831 件。ただし 2025 年のデータはなく、run metadata と統合済み `records.json` も
確認されていない。収集ログには quota error とページ単位の欠損が記録されており、
連続した10年系列としては未完了である。

## 確認された観測

- 年別件数: 2016=507、2017=504、2018=457、2019=532、2020=540、
  2021=533、2022=550、2023=61、2024=147。
- 2025 年のファイルなし。収集ログでは 2025 年 0 件と記録。
- `collection_log.txt` はあるが `run_metadata.json` はない。
- `records.json` に統合されていない（年別ページファイルを個別に保持）。
- 収集ログには `quota_limit_value: 100` による失敗が記録されている。

## 影響

3,831 件という総数だけでは、欠損年・部分取得年・ページネーション失敗を把握できない。
10年の動画公開推移や年別件数を完全系列として報告することはできない。
また、収集 API / パラメータ / run の完全な provenance が確保されていない。

## 対応方針

- 現行の年別 raw ファイルを変更・統合・削除しない。
- 83 ファイルの件数を再集計する再現可能な downstream 検証を用意する。
- run metadata が発見できないフィールドを捏造しない。欠損は明示する。
- 2025 年の補完を行う場合、利用可能な収集方法・規約・費用を確認し、別 run として承認後に実施する。

## 完了条件
