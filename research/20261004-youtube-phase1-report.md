## 主要な発見

### 1. データの分布

| 化合物 | 特徴 |
|--------|------|
| **CBD** | 2016-2022年に多数のデータ（年間400-550件）、2023年以降は減少 |
| **CBG** | 2017年にのみ50件、他の年は0件 |
| **THC** | 2023年のみ50件、他の年は0件 |
| **CBN** | 全期間で0件（日本語圏での動画が少ない） |

### 2. CBD の長期推移

| 期間 | 年間平均 | 状態 |
|------|:--------:|------|
| 2016-2019 | 約500件 | 安定・高需要 |
| 2020-2022 | 約540件 | 高需要継続 |
| 2023-2025 | 約70件 | **急減** |

### 3. データの限界

| 限界 | 内容 |
|------|------|
| **地域制限** | 日本（regionCode=JP）のみ |
| **多義語問題** | CBD, THC は多義語の可能性あり |
| **API 制限** | 1回の検索で最大50件（ページネーションで補完） |
| **低ボリューム** | CBG, CBN は日本語圏での動画が少ない |
