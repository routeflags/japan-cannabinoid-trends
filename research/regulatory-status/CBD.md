## 1. 日本における法的扱い

| 項目 | 内容 |
|------|------|
| **法的扱い** | **非規制（条件付き合法）** |
| **規制カテゴリ** | 大麻取締法（2024年12月改正後） |
| **法令名** | 大麻草の栽培の規制に関する法律（大麻取締法） |
| **現行法の施行** | 2024-12-12（第一段施行） |
| **成分規制への移行** | 2024-12-12 |
| **出典** | [厚生労働省 大麻規制のあり方](https://www.mhlw.go.jp/content/11120000/000995181.pdf) |

---

## 2. 規制の内容

### 合法化の条件

| 条件 | 内容 |
|------|------|
| **THC含有量** | 検出されないこと（0.00%） |
| **第三者機関検査** | COA（分析証明書）が必要 |
| **製造元** | 厚生労働省許可事業者 |
| **輸入** | 厳格な書類審査 |

### 改正大麻取締法のポイント（2024年12月施行）

1. **部位規制から成分規制へ移行**
   - 従来: 花穂・葉が違法、茎・種子が合法
   - 改正後: THCそのものを規制対象とする

2. **使用罪の新設**
   - 最大7年の懲役刑

3. **医療大麻の条件付き解禁**
   - 厚生労働大臣の承認があれば医師が処方可能

4. **THC残留限度値の設定**
   - CBD製品に含まれるTHCの上限値を規定
