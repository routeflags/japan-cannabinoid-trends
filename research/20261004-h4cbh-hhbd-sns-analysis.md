## 1. 分類方法（Methodology）

### 1.1 分類プロセス

| 項目 | 内容 |
|------|------|
| **分類対象** | 各化合物の取得投稿（n=40） |
| **分類方法** | キーワードマッチング + 手動確認 |
| **分類者** | 単一コーダー（自動生成 + 人手調整） |
| **検証** | サンプル抽出による目視確認（n=10） |

### 1.2 分類カテゴリ定義

| カテゴリ | 定義 | 判定基準 |
|---------|------|---------|
| **製品宣伝・販売** | 製品の販売・宣伝を目的とする投稿 | 「取扱」「再入荷」「新規」「価格」等のキーワードを含む |
| **製品レビュー** | 製品の使用感・意見を述べる投稿 | 個人の使用経験への言及を含む |
| **会話・引用** | リプライ・メンション・引用付き投稿 | 対話形式の投稿 |
| **その他** | 上記に該当しない投稿 | 情報収集、質問等 |

### 1.3 分類の限界

1. **単一コーダー:** インターコーダー信頼性（Cohen's kappa）は測定していない
2. **サンプルバイアス:** `section=latest` のため、期間内の最新投稿が中心（ランダムサンプルではない）
3. **偽陽性の可能性:** キーワード「H4CBH」を含むが、別製品（CBX等）に言及している投稿が含まれる場合がある
4. **自動生成:** 分類は自動処理 + 手動調整であり、完全な人手分類ではない
