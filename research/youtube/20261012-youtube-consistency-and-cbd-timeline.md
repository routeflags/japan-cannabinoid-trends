## 1. 背景とデータの取り扱い

本 dataset の開発過程で一時導入された **YouTube Data API v3** 版の収集
（`youtube_api_date_range.py`、現在は削除済み）により、
「CBD リキッド」の 2016-01〜2019-12 月次ウィンドウデータが取得された。

しかし YouTube Data API v3 は本リポジトリの方針
（`datasets/youtube-consistency/README.md` の利用規約上の制約）に照らして使用対象外と判断された。
**2026-10-12 に方針決定を行い、v3 由来の全 run（`collector='youtube-api'`）を raw 層から削除した。**

本レポートは、削除前に DB から抽出した**集計値（derived data）**を記録したものである。
raw レコード（video_id 単位の明細）は保存せず、再取得もしない。
数値は削除前スナップショット（バックアップ）に基づく。

## 2. 一貫性検証（完了）

同一クエリ「CBD リキッド」を連続 6 回取得した結果:

| 指標 | 値 |
|------|-----|
| Run 数 | 6 |
| 出現総数（run × video） | 234 |
| ユニーク動画数 | 39 |
| **全 Run 一致率** | **39 / 39 = 100%**（6 回全てが同一 39 動画） |

**解釈**: 直近窓（`dateFilter: month` 相当）では、
短時間の連続取得において検索結果が完全に再現されることを確認した。
これは README 記載の「`dateFilter: month` は重複率 100%」という既存知見と整合する。

## 3. CBD リキッド 月次タイムライン（2016–2019、削除前集計）

対象: 「CBD リキッド」を月次ウィンドウ（`published_after`〜`published_before`）で取得。
各ウィンドウの record_count（ユニーク動画数）。

### 3.1 年次合計

| 年 | ユニーク動画数（その年に公開された動画） |
|----|------------------------------------------|
| 2016 | 17 |
| 2017 | 25 |
| 2018 | 53 |
| 2019 | 86（10 月ウィンドウ分は DB 未反映のため過少の可能性） |
| **合計** | **181**（月次 TSV 上の取得動画数。下記注意参照） |

### 3.2 月次推移（抜粋）

- 2016: 低位で推移（1〜4 件/月、7・8 月は 0 件）
- 2017: 1〜6 件/月へ緩やかに増加
- 2018: 2〜12 件/月へ増加（12 月 10 件）
- 2019: 5〜12 件/月で高位安定（ピークは 2 月 12 件、3 月 11 件、9 月 11 件）

### 3.3 公開年分布（Apify 全期間スナップショット、参考）

**観察**: 月次ウィンドウ（YouTube Data API v3 由来）と

その後 2022 年以降は減少傾向にあることが整合して観察される。

## 4. 限定事項

1. **集計値のみ保存**: raw（video_id 明細）は削除済み。本レポートの数値は再現不可の一次性派生値。
2. **2019 年は過少の可能性**: 10 月ウィンドウ分が反映前だったため、2019 年合計 86 件は下限値。
3. **検索結果は関連度ベース**: YouTube の関連度ランキングに依存し、網羅的な全動画普查ではない。
4. **非因果**: 公開件数の増減は市場・規制・プラットフォーム要因を含みうる。時系列的観察にとどまる。
