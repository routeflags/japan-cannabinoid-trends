## 分析結果の解釈

### 観測（Observations）

1. **日本語コンテンツの割合は化合物によって異なる**
   - CBD: 一定の日本語コンテンツが存在
   - CBG, THC, CBN: 日本語コンテンツが非常に少ない

2. **重複データの存在**
   - ページネーションによる重複が確認される
   - ユニークID数でカウントし直す必要がある

3. **日本語コンテンツの減少傾向**
   - CBD では2023年以降、日本語コンテンツも減少している可能性

### 解釈（Interpretations）

1. **低日本語率の原因**
   - YouTube API の `regionCode=JP` は言語でフィルタしない
   - 英語キーワード（CBD, CBG, THC）は国際的なコンテンツを引き寄せる
   - 日本語キーワード（「CBD オイル」「カンナビノイド」）が必要

2. **データの限界**
   - 現在のデータは「YouTube API の検索挙動の記録」としては有用
   - しかし「日本のカンナビノイド動画コンテンツの趋势」を示すものではない
