化学構造の扱い: 表記の違いは検索文字列の違いであり、本ページは THC-O と THCO を同一の検索需要として扱わない。Δ8-THC-O / Δ9-THC-O などの異性体・構造の帰属も断定しない。canonical とバリアントの値の差は、2 つの検索文字列の観測差であって、物質の違いの測定ではない。

制約: 各 run は自分のピーク = 100 に正規化され、窓も canonical の 5年 run（2021-10-10 〜 2026-10-11）と異なるため、窓をまたいだ数値比較をしない。非ゼロ週の差（canonical 19 / バリアント 90）は、2 つの検索文字列の観測差であり、canonical 系列の修正ではない。バリアントの平均・ピークは本ページに載せない（本ページが載せるのは週数と非ゼロ週で、いずれも run の系列長の記録である）。
