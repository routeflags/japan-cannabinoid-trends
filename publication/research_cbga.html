このセクションでは、本ページの情報がどのように収集・分析されたかを公開しています。

研究質問

「日本における登録検索語 CBGa（owner の意図は cannabigerolic acid、標準表記 CBGA）へのオンライン関心は、どのように推移しているか？」

最終更新: 2026-11-11。

登録と同一性: 本ページの CBGa は、owner が 2026-11-11 に cannabigerolic acid（カンナビゲロール酸、標準表記 CBGA） を指すと確認した登録語である。taxonomy の compound_cbga は ChEBI 67081、Wikidata Q27135612、FDA GSRS の UNII 80I4ZM847Y 記録（CAS 25555-57-1、PubChem CID 6449999、C22H32O4）で識別子を検証し、compound_minor（非主要フィトカンナビノイド）に置いている。CBG は CBGA の脱炭酸体であり別名ではない。owner の表記 CBGa（小文字の a）はそのまま保存し、登録クエリ文字列を変更しない（datasets/cannabinoid-raw-collection/methodology.md §1.3、ISS-20261111-TAX-040 追記）。ただし本ページが測るのは CBGa / CBGa リキッド という検索文字列への一致であり、各結果が cannabigerolic acid を扱っていることの確認ではない。既存の検索需要・YouTube サンプルは文字列一致の観測であり、内容の関連性の証明ではない。

本ページの範囲: Google Trends の 5年・12ヶ月（いずれも no data）と、YouTube の検索結果サンプル 1 run の集計だけを扱う。X は収集していない。規制・COA は扱わない。共通スケール（compare_terms）の要求は、この登録語について未収集である。

データソース

  • 検索データ: Google Trends（日本、過去5年・過去12ヶ月とも no data）
  • 動画データ: YouTube Search via Apify（検索語「CBGa リキッド」、89 件）
  • X: この登録語では収集していない（0 件の観測ではない）。
  • 規制資料: 本ページでは扱わない（cannabigerolic acid の規制状態は本ページの対象外で、規制資料を収集・評価していない）。
  • 収集手段と collector: Google Trends は google-trends-mcp 0.1.1（2026-11-10 に試行、no data）、YouTube は Apify の streamers/youtube-scraper build 0.0.329（2026-11-10 収集）。
  • 合算しない: Google Trends の相対指数と YouTube の返却サンプル件数は異なる現象であり、合算・換算しない。
  • 値の区分: 観測（run が返した返却点・返却件数）と派生（平均・年次件数・ピーク月・再生数統計）を区別する。推移の解釈は行わない。

データソース: Google Trends / 地域: 日本 (JP) / 要求: today 5-y（no data）・today 12-m（no data） / 取得日: 表ごとの出所を参照

用語の定義:

  • 単独系列: 1 語だけを取得した系列。その語のピークが 100。
  • 共通スケール: 複数語を同じ要求で取得した系列。要求内の最大値が 100。登録語間で比べられるのはこちらだけ。
  • 興味度スコア: Google Trends が返す相対指数（0-100）。絶対検索数ではなく、期間内の最大検索量を 100 とした相対値。

部分年: 2013・2026 は、その年の観測日数分の件数であり、年間全体の件数ではない。公開日がサンプルにない年は行を作らない（未取得を 0 にしない）。

制約: 月次・年次件数は返却サンプル内の公開日件数であり、YouTube 全体の投稿数を表さない（全動画を網羅するものではない）。結果上限は宣言に maxResults=500 と記録され、返却件数はその上限未満である。ただし返却サンプルは一致する動画の総数ではなく、検索の到達範囲も記録からは確定できない。再生数は取得日時点の値であり、変動する可能性がある。0 の再生数は返却値であり欠測ではない。未取得を 0 観測として扱わない。他の検索語・run と合算せず、date_filter の異なる run 間は比較しない。動画単位の行（動画 ID・タイトル・チャンネル・URL・再生数）は公開しない（集計のみ、ISS-20261015-COL-030 §4.1）。

検索語の限界: 返却は検索語「CBGa リキッド」の文字列一致によるサンプルであり、動画の内容が登録語の物質を扱っていることを確認していない（略号・一般語との衝突を含む）。日本語の製品語「リキッド」は近似的な日本市場限定で、geo フィルタではない。

出所: run 20261110T194826Z-youtube-cannabinoid-raw-collection（date_filter=all / 2026-11-10T19:48:26Z 開始・2026-11-10T19:50:43Z 終了、返却 89 件）。採用宣言は metadata/provenance/declarations/20261110-youtube-cbga-cannabinoid-raw-collection.json の該当 run で、payload SHA-256 は同宣言の environment.payload_sha256（5d4b8bc1…fe2d33）。raw payload と run 記録は Git 非追跡・非公開のため、本節の年次・月次件数と再生数統計は収集時 payload の集計値であり、リポジトリからは再計算できない（採用宣言はリポジトリにある）。

照合: 年次合計は返却件数と一致する（89）。ピーク月は返却サンプル内の最多月で、同点の月は併記する（2022-03 が 5 件）。再生数統計は返却レコードの値の単純集計（平均は算術平均、中央値は件数が偶数のとき中央 2 値の平均）。月次全点は掲載せず、年次分布とピーク月のみを載せる。

公開状態

公開状態: 公開審査待ち（requires_review）。本ページは 2026-11-11 に作成したドラフトである。公開契約の review envelope（metadata/publication/research-cbga/）はまだ無く、公開判断・hash の固定は行っていない。

図は差し込んでいない（5年推移・年次分布・共通スケールのいずれも未作成）。図の生成は、ページ記載値と raw の照合に加えて、5年 compare_terms 要求（CBD・THC を同一要求に含む）を必要とする。この登録語についてその要求が未収集のため、図の生成・差し込みは行っていない。

公開する場合は、C1〜C45 の内容レビュー、review envelope の作成、図の生成・差し込み、hash の再固定、公開契約監査の再実行が必要である。
