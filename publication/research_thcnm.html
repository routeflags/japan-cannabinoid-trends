再現性チェックリスト

  • run ごとに run 識別子と query_id を併記する（本ページの全数値の出所）。
  • Google Trends の窓は metadata/windows/ の登録窓（12ヶ月 2025-11-02_2026-11-08、3ヶ月 2026-08-06_2026-11-04、5年 2021-10-31_2026-11-08）で、観測範囲は返却点の範囲として別に記録する。
  • Google Trends の単独系列は raw の payload.json・records_thcnm.json・artifact-manifest.json（SHA-256）を証跡とする。共通スケールは payload.json・comparison_cbd-thc-thcnm.json・artifact-manifest.json。
  • 単独系列と共通スケールは別 run・別の正規化である。片方の値をもう片方へ換算しない。
  • YouTube は採用宣言（staging-declaration-v1）と run 記録をリポジトリ側の証跡とし、payload は Git 非追跡。
  • 平均は週次・日次値の算術平均、非ゼロ点は値が 0 でない週数・日数。集計は run をまたがない。
  • 各検索語は単発 run で、反復実行による安定性は未測定。

用語の定義:

  • 単独系列（個別正規化値）: 各キーワードを個別に取得した系列。その run の最大値を 100 とする正規化であり、キーワード間・run 間の比較には使用できない。
  • 共通スケール: 複数語を同じ compare_terms 要求で取得した系列。その要求の最大値を 100 とする正規化で、同じ要求の中だけで比較できる。単独系列とは別の物差しであり、換算できない。
  • 興味度スコア: Google Trends が返す相対指数（0-100）。絶対検索数ではなく、期間内の最大検索量を 100 とした相対値。
  • 0 の意味: 系列の最小値（閾値未満）を表す観測値であり、検索が存在しなかったことや欠測を意味しない。
  • 窓: today 12-m / today 3-m / today 5-y という相対指定を、記録した reference time で登録窓に名目解決したもの。実際の境界は未検証（exact_window_match: false）。表の観測範囲は検索条件ではなく、返却された点の範囲である。

窓の解決 today 12-m / today 3-m / today 5-y は reference time で名目解決された要求であり、実際の境界は未検証（exact_window_match: false）。観測範囲を検索条件として読まない
系列間比較 単独系列と共通スケールは正規化が別で、換算できない。12ヶ月・3ヶ月・5年は窓も別なので、平均を比較できない。単独系列の値を化合物間・run 間で比べない
共通スケールの解像度 12ヶ月共通スケールの THCNM が全週 0 なのは、窓内最大値（CBD の 2026-05-03 = 100）に対して小さく、相対指数の整数に丸められたため。需要ゼロや欠測ではない
3ヶ月の孤立値 3ヶ月共通スケールの THCNM は 2026-08-13 だけ 12 で、前後は 0。同時期の12ヶ月単独系列（2026-08-09 の週）は 0 であり、2 つの測定は一致しない。理由は未確認で、本ページでは解釈しない
5年の被覆 アンカー付き5年共通スケール run（20261104T195136Z）で取得済み。THCNM は全 262 週 0（丸め）。既存の5年単独系列を共通スケールとして扱わない
0 の意味 0 は相対指数の最小値（閾値未満）であり、需要ゼロや欠測を意味しない
反復の欠如 各検索語は単発 run。同一条件の反復が無く、API の非決定性による系列の安定性は未測定
YouTube の地域 API の地域フィルタが無く、「リキッド」という日本語製品語による近似。日本国内に限定された観測ではない
YouTube の被覆 返却された検索結果の標本であり全数ではない（maxResults 500 に対し 30 件 / 311 件）。動画単位の指標は掲載しない
同一性 THCNM の化学的同一性は未確認。THA は別名・商業名であり、本ページは同一物質とも別物質とも断定しない
法的地位 THCNM の法的地位は物質の同一性に依存するため、本ページでは判定しない。規制資料は対象外であり、本ページを法的評価として読まない
欠測の扱い X は未収集。規制資料・COA・価格は本ページの対象外。未収集を 0 観測として扱わない
配布物との関係 本ページの THCNM 系列は、配布物 datasets/cannabinoid-platform-trends/ の公開化合物集合に含まれない
