項目 内容

検索クエリと化学的同一性（区別）

本ページの数値は、登録された検索文字列に一致する検索需要と検索結果の観測であり、物質の検出・存在・同一性の証拠ではない。次の区別を保つ。

項目 内容
登録 THCNM は taxonomy に compound_thcnm として登録され、暫定的に半合成（compound_semisynthetic）に配置されている
THA の位置づけ 別名・商業名として登録されている。化学的同一性は未確認であり、THCNM と同一の物質であるとも別の物質であるとも断定しない（ISS-20261104-TAX-028）
識別子 CAS 番号・ChEBI / PubChem / Wikidata ID・分子式は、この同一性について検証済みの値が無いため記載しない
混同しないもの THAH（別の独自ブレンド）および THC-O（別化合物。表記バリアント THCO の run を含む）とは別概念。THC-O の run は本ページの観測に含めない
観測の意味 検索語の一致は、その名称で検索・言及された内容の観測であり、表示された製品の成分や物質の流通量ではない

再現性チェックリスト

  • run ごとに run 識別子と query_id を併記する（本ページの全数値の出所）。
  • Google Trends の窓は metadata/windows/ の登録窓（12ヶ月 2025-11-02_2026-11-08、5年 2021-10-31_2026-11-08）で、観測範囲は返却点の範囲として別に記録する。
  • Google Trends は raw の payload.json・records_thcnm.json・artifact-manifest.json（SHA-256）を証跡とする。
  • YouTube は採用宣言（staging-declaration-v1）と run 記録をリポジトリ側の証跡とし、payload は Git 非追跡。
  • 平均は週次値の算術平均、非ゼロ週は値が 0 でない週数。集計は run をまたがない。
  • 各検索語は単発 run で、反復実行による安定性は未測定。

データソース: Google Trends via google-trends-mcp / 地域: 日本 (JP) / 検索文字列: THCNM / 取得日: 2026-11-04

登録文字列 THCNM の日本国内の検索関心度（相対指数 0-100）を、12ヶ月と5年の 2 本の単独系列として取得した。2 系列は別 run の別観測である。

用語の定義:

  • 単独系列（個別正規化値）: 各キーワードを個別に取得した系列。その run の最大値を 100 とする正規化であり、キーワード間・run 間の比較には使用できない。
  • 興味度スコア: Google Trends が返す相対指数（0-100）。絶対検索数ではなく、期間内の最大検索量を 100 とした相対値。
  • 0 の意味: 系列の最小値（閾値未満）を表す観測値であり、検索が存在しなかったことや欠測を意味しない。
  • 窓: today 12-m / today 5-y という相対指定を、記録した reference time で登録窓に名目解決したもの。実際の境界は未検証（exact_window_match: false）。表の観測範囲は検索条件ではなく、返却された週次点の範囲である。

公開状態

本ページは公開審査待ち（requires_review）である。公開契約 PC-7 の審査 envelope は metadata/publication/research-thcnm/ にあり、判断状態は approved ではない。したがって外部公開・リリースは行っていない。

2026-11-04 に validation.cli audit-publication と gate-publication を実行した。公開契約の機械検査は本ページについて finding 0、公開適格ゲートは BLOCKED（PUB-04 個人データ審査、PUB-10 公開承認）であり、未承認のままである。審査の詳細と次の作業は envelope の decision.json / evidence.json に記録する。

平均・非ゼロ週・観測範囲の算出方法は src/processing/gt_statistics.py と同じ定義（週次値の算術平均、値が 0 でない週数、返却点の最小・最大）による。
