研究質問

「日本において、登録検索語 (6aS,9R,10aR)-HHC に一致する検索需要と、リキッド検索語 (6aS,9R,10aR)-HHC リキッド の検索結果サンプルは、どのように収集され、どのような状態にあるか？」

最終更新: 2026-11-15。

study: cannabinoid-raw-collection（datasets/cannabinoid-raw-collection/）。

登録と同一性: 本ページの (6aS,9R,10aR)-HHC は、2026-11-15 に候補表から検索トピックとして登録された検索文字列である（ISS-20261115-TAX-045）。taxonomy の管理カテゴリ compound_identity_unverified に置かれ、化学的同一性は未確認である。本ページは名称・構造・化学クラス・天然存在・経路／由来・別名・規制状態を主張せず、測っているのは登録文字列に一致する検索需要と検索結果サンプルである（datasets/cannabinoid-raw-collection/methodology.md §1.3）。本語の形式辞書の行は、WHO 47th ECDD (2024) §2C のレビューが可能な配置として図示するのみで、個別の registry record も製品同定も未確認である（datasets/cannabinoid-raw-collection/README.md の形式辞書）。

本ページの範囲: Google Trends の単独系列（12ヶ月・5年）の収集状態と、YouTube の liquid-only primary 1 query の収集状態だけを扱う。系列値・返却件数は載せない。X は収集していない（X 設計外。0 件の観測ではない）。共通スケール（compare_terms）の要求は未収集である。規制・COA は扱わない。

データソース

  • 検索データ: Google Trends（日本、単独系列。過去12ヶ月・過去5年の状態は下表のとおり）
  • 動画データ: YouTube Search via Apify（検索語「(6aS,9R,10aR)-HHC リキッド」、product_liquid）
  • X: この登録語では収集していない（X 設計外。0 件の観測ではない）
  • 規制資料: 本ページでは扱わない（登録語の同一性が未確認のため、規制状態を推定しない）
  • 収集手段と collector: Google Trends は google-trends-mcp 0.1.1（collect --live、2026-11-15 収集）。YouTube は Apify の streamers/youtube-scraper（2026-11-15 実行、build の記録なし）。
  • geo とクエリ言語の限界: metadata/queries/query-registry.json の language: ja は登録メタデータであり、API の言語フィルタではない。要求・run の記録が支えるフィルタだけを主張する。Google Trends は geo=JP を要求に含む（plan の query.geo。採用 run がある場合は run の submitted_parameters.geo も JP）。YouTube の actor input には geo パラメータも言語パラメータも無く、日本語の製品語「リキッド」による近似的な日本市場限定であり、geo 保証でも言語フィルタでもない（methodology.md §1.4）。
  • 合算しない: Google Trends の相対指数と YouTube の検索結果サンプルは異なる現象であり、合算・換算しない。
  • 値の区分: 本ページは観測値・派生値を載せず、ソース別の収集状態だけを記録する。

公開状態

公開状態: 公開審査待ち（requires_review）。本ページは 2026-11-15 に作成したドラフトである。公開契約の review envelope（metadata/publication/research-6as-9r-10ar-hhc/）はまだ無く、公開判断・hash の固定は行っていない。

図は差し込んでいない。5年の推移図は採用された 5年系列を必要とするが、この登録語の 5年は採用 run を持たない（未試行）。共通スケールの図は compare_terms の run を必要とするが、この登録語には無い。YouTube の集計図は採用 raw の公開審査を必要とする。したがって図の生成・差し込みは行っていない。

公開する場合は、C1〜C45 の内容レビュー、review envelope の作成、5年系列・共通スケールを追加収集するか、状態のみで公開するかの判断、hash の固定、公開契約監査の再実行が必要である。
