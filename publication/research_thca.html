研究質問

「日本におけるTHCA（登録検索語）へのオンライン関心は、どのように推移しているか？」

最終更新: 2026-11-11。

登録と同一性: 本ページの THCA は、study の管理上の登録状態カテゴリ compound_identity_unverified に登録された検索文字列である。化学的同一性は未確認で、本ページは名称・構造・化学クラス・天然存在・経路／由来・別名・規制状態を主張しない（datasets/cannabinoid-raw-collection/methodology.md §1.3）。測っているのは登録文字列に一致する検索需要と検索結果サンプルである。

総称検索文字列のページである: 2026-11-11 の owner 確認により、総称 THCA とは別の検索トピックとして Δ9-THCA-A・THCA-B・Δ8-THCA を登録した（ISS-20261111-TAX-041）。本ページは登録文字列 THCA 自体の系列を扱う総称文字列のページであり、本ページの Google Trends 系列と YouTube サンプルを新しい 3 トピックへ割り当てていない。3 トピックには現時点で収集データが無く、本ページの数値で代用しない（未収集は 0 観測でも欠測でもない）。

本ページの範囲: Google Trends の単独系列（5年・12ヶ月）と、YouTube の検索結果サンプル 1 run の集計だけを扱う。X は収集していない。規制・COA は扱わない。共通スケール（compare_terms）の要求は、この登録語について未収集である。

データソース

  • 検索データ: Google Trends（日本、過去5年・過去12ヶ月）
  • 動画データ: YouTube Search via Apify（検索語「THCA リキッド」、NO_VIDEOS）
  • X: この登録語では収集していない（0 件の観測ではない）。
  • 規制資料: 本ページでは扱わない（登録語の同一性が未確認のため、規制状態を推定しない）。
  • 収集手段と collector: Google Trends は google-trends-mcp 0.1.1（2026-11-10 収集）、YouTube は Apify の streamers/youtube-scraper build 0.0.329（2026-11-10 に実行、NO_VIDEOS）。
  • 合算しない: Google Trends の相対指数と YouTube の返却サンプル件数は異なる現象であり、合算・換算しない。
  • 値の区分: 観測（run が返した返却点・返却件数）と派生（平均・年次件数・ピーク月・再生数統計）を区別する。推移の解釈は行わない。

公開状態

公開状態: 公開審査待ち（requires_review）。本ページは 2026-11-11 に作成したドラフトである。公開契約の review envelope（metadata/publication/research-thca/）はまだ無く、公開判断・hash の固定は行っていない。

図は差し込んでいない（5年推移・年次分布・共通スケールのいずれも未作成）。図の生成は、ページ記載値と raw の照合に加えて、5年 compare_terms 要求（CBD・THC を同一要求に含む）を必要とする。この登録語についてその要求が未収集のため、図の生成・差し込みは行っていない。

公開する場合は、C1〜C45 の内容レビュー、review envelope の作成、図の生成・差し込み、hash の再固定、公開契約監査の再実行が必要である。
