## 3. 制約事項

> **修正 (2026-10-02):** 以前「過去データは遡及取得不可」と記載していたが、**誤り** であることを確認した。`since:` / `until:` 演算子を使用することで、日付指定での過去データ取得が可能である。

| 期間 | 可否 | 理由 |
|------|------|------|
| 2026年5月 | ✅ 可能 | `since:` / `until:` で日付指定可能 |
| 2026年6月 | ✅ 可能 | 同上 |
| 2026年7月 | ✅ 可能 | 同上 |
| 2026年8月 | ✅ 取得済み | 147件（tweet_id ベースで重複排除済み） |

> **注:** 完全な網羅性は保証されない。検索結果の非決定性により、同一クエリでも結果が変動する場合がある。

### 3.2 取得結果の解釈

> **修正 (2026-10-02):** 以前「シャドウバン」と記載していたが、**未検証** である。

2026年9月17日の取得では、以下のクエリが全て0件を返した:

- `CBX リキッド`（主要クエリ）
- `CBX`（単体）
- `カンナビノイド CBX`（複合クエリ）
- `新成分 リキッド カンナビノイド`（代替クエリ）
- `合法リキッド 新成分`（代替クエリ）

**可能性がある原因:**

1. **X のシャドウバン** — カンナビノイド関連コンテンツの API 制限
2. **`chargedEventCounts` の不正確さ** — 実データが存在しても 0 と報告されるケースを確認済み
3. **検索インデックスの取りこぼし** — 検索結果の非決定性による一時的な空結果

> **注意:** シャドウバンの存在を裏付ける直接的な証拠はない。後日、`since:` / `until:` を使用した9月分の取得で20件のデータが取得できており、完全なブロックは確認されていない。
